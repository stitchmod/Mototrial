# GRAVEL // TRIAL

Браузерный мототриал на HTML и JavaScript: вид сбоку, 2.5D-графика Three.js и физика Matter.js.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Локальный просмотр сборки: `npm run preview`.

## Управление

- **W / ↑** — газ.
- **S / ↓** — тормоз, затем задний ход.
- **A / ←** — перенос веса назад.
- **D / →** — перенос веса вперёд.
- **R** — возврат к последней контрольной точке (с добавлением ошибки).
- **P / Esc** — пауза.
- **M** — звук.
- На сенсорных экранах доступны экранные кнопки.

## Игровой цикл

Три трассы с разным рельефом, брёвнами, камнями, ящиками и качающимися мостами. Заезд включает старт, контрольную точку, финиш, падения и повторные попытки. Время и ошибки определяют медаль; следующая трасса открывается после финиша. Лучшие результаты, открытые трассы и настройка звука хранятся в `localStorage` текущего браузера и не синхронизируются между устройствами.

## Реализация

- Фиксированный шаг физики 60 Гц.
- Отдельные физические тела рамы и колёс, связи подвески, крутящий момент заднего колеса и управление наклоном.
- Процедурные CanvasTexture для грунта, камня, дерева и металла; внешние изображения не требуются.
- Синтез звука через Web Audio, объекты частиц переиспользуются.
- Автоматическое отключение теней на программных графических адаптерах.

Three.js и Matter.js распространяются по лицензии MIT. Модель мотоцикла, гонщика, трассы и текстуры созданы процедурно для этого проекта; сторонние игровые ассеты не используются.
